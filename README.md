# AI-first software engineer. Building in Rust.

I build software with AI coding agents — defining requirements, guiding implementation, and reviewing and validating changes.

My foundation is production backend engineering with **Node.js, TypeScript, and PostgreSQL**. Today, Rust is my language of choice for new projects, with a focus on local speech software and reusable libraries.

## Selected projects

**[gigastt](https://github.com/ekhodzitsky/gigastt)** — Local speech recognition. Transcribe files, serve HTTP/WebSocket clients, or embed the Rust engine. Powered by GigaAM; inference runs on your device.

**[polyvoice](https://github.com/ekhodzitsky/polyvoice)** — CPU speaker diarization: who spoke when. Native INT8 kernels, with Rust, Python, C, and CLI interfaces.  
[Documentation](https://github.com/ekhodzitsky/polyvoice#readme) · [Benchmarks](https://github.com/ekhodzitsky/polyvoice#speed)

**[ryf](https://github.com/ekhodzitsky/ryf)** — WAVE and telephony codecs in Rust. No default dependencies; tested against ffmpeg and malformed inputs.

**[rupunct](https://github.com/ekhodzitsky/rupunct-rs)** — Russian punctuation and casing restoration. Local Q8 inference, available as a Rust library and CLI.
